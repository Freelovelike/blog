# 快速启动脚本使用指南

## 概述

本项目提供了快速启动脚本，可以一键启动所有三个服务（后端、前台、后台），大大简化了开发环境的启动流程。

## 脚本列表

### PowerShell 脚本（推荐）
- `start-all.ps1` - 启动所有服务
- `stop-all.ps1` - 停止所有服务

### Windows 批处理脚本
- `start-all.bat` - 启动所有服务（简化版）
- `stop-all.bat` - 停止所有服务

## 使用说明

### 1. PowerShell 脚本（功能完整）

```powershell
# 启动所有服务
.\start-all.ps1

# 停止所有服务
.\stop-all.ps1
```

#### 功能特点：
- ✅ **依赖检查**：自动检查 bun 和 Go 是否安装
- ✅ **端口管理**：自动清理端口占用，避免冲突
- ✅ **健康检查**：验证后端服务是否正常启动
- ✅ **优雅启动**：按顺序启动服务（后端→前台→后台）
- ✅ **统一停止**：一键停止所有相关进程
- ✅ **状态显示**：彩色输出，清晰显示服务状态
- ✅ **错误处理**：完善的错误提示和恢复机制

#### 服务端口：
- 后端服务：http://localhost:8080
- 前台服务：http://localhost:3000  
- 后台服务：http://localhost:3001
- API文档：http://localhost:8080/swagger/index.html

### 2. Windows 批处理脚本（简化版）

```cmd
# 启动所有服务
start-all.bat

# 停止所有服务
stop-all.bat
```

#### 特点：
- ⚡ 启动速度快
- 🎯 操作简单
- 🪟 原生 Windows 支持
- ⚠️ 功能相对简化

## 启动流程

### PowerShell 脚本启动流程：

1. **环境检查**
   - 检查 bun 是否安装
   - 检查 Go 是否安装

2. **端口清理**
   - 检查 8080、3000、3001 端口是否被占用
   - 自动终止占用进程

3. **服务启动**
   - 启动后端服务（端口 8080）
   - 等待 3 秒，进行健康检查
   - 启动前台服务（端口 3000）
   - 启动后台服务（端口 3001）

4. **状态显示**
   - 显示所有服务的访问地址
   - 提供服务管理提示

## 常见问题

### Q1: 脚本无法执行？
**解决方案：**
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Q2: 端口被占用？
**解决方案：**
脚本会自动检测并清理端口，如果失败可以手动终止：
```powershell
# 查看端口占用
Get-NetTCPConnection -LocalPort 8080

# 终止进程
Stop-Process -Id <进程ID>
```

### Q3: 服务启动失败？
**解决方案：**
1. 检查依赖是否安装：
   ```powershell
   bun --version
   go version
   ```
2. 查看项目日志
3. 尝试手动启动单个服务

### Q4: 如何修改默认端口？
**解决方案：**
编辑脚本文件，修改开头的端口变量：
```powershell
$BACKEND_PORT = 8080      # 修改后端端口
$FRONTEND_PUBLIC_PORT = 3000  # 修改前台端口
$FRONTEND_ADMIN_PORT = 3001   # 修改后台端口
```

## 开发建议

### 日常使用
1. **开发时**：使用 `start-all.ps1` 一键启动所有服务
2. **调试时**：使用 `stop-all.ps1` 快速停止，修改代码后重新启动
3. **部署时**：建议手动启动，便于问题排查

### 最佳实践
1. **保持脚本更新**：项目结构变更时同步更新脚本
2. **监控资源**：长时间开发注意内存使用情况
3. **定期重启**：建议每隔几小时重启一次服务
4. **日志记录**：重要操作建议记录日志

### 性能优化
1. **按需启动**：只启动需要的服务
2. **资源监控**：关注 CPU 和内存使用
3. **缓存清理**：定期清理构建缓存
